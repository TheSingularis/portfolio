# Resume/CV File

Place your resume file here as `resume.pdf` (or update the path in `src/data/portfolio.json`).

## Instructions:
1. Export your resume as a PDF file
2. Name it `resume.pdf` and place it in the `public` folder
3. Or update the `resume` field in `src/data/portfolio.json` to match your filename

## Supported formats:
- PDF (.pdf) - Recommended
- Word Document (.doc, .docx)
- Other document formats

The download link will appear in the Contact section with a document emoji and "Download Resume" text.
